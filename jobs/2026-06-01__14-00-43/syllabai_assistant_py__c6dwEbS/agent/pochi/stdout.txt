### `python3 main.py ask "<question>" --course-id <course_id>`
- Calls `client.v1.context.search()` with:
  - `query=<question>`
  - `minimum_similarity_threshold=0.3`, `similarity_threshold=1.0`
  - `scope="internal"`
  - `body_metadata={"group_name": ["syllabus", "<course_id>"]}`
- Extracts context chunks from the search response
- Builds a prompt combining the retrieved context with the user's question
- Calls OpenAI Chat Completions (`gpt-4o-mini`) to generate the answer
- Prints: `Answer: <model response>`

## Key Design Decisions
- **API keys** read from `ALCHEMYST_AI_API_KEY` and `OPENAI_API_KEY` environment variables (no hardcoded keys)
- **`course_id`** used verbatim from CLI (already namespaced by `ZEALT_RUN_ID`)
- **`file_name`** derived from `course_id` for uniqueness across re-runs
- **`group_name`** metadata includes both `"syllabus"` and the `course_id` for scoped retrieval (Context Arithmetic)
- **`body_metadata`** used on the search call (maps to the API's metadata filter field, since `metadata` param on search is a query string for response metadata inclusion)
- SDK method signatures verified against the actual `alchemystai==0.10.0` package source code

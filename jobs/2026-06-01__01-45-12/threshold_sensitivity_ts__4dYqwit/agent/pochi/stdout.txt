# Alchemyst AI — Similarity Threshold Sensitivity (TypeScript SDK) ## Background Alchemyst AI's context search accepts a `similarity_threshold` parameter that controls how closely a chunk must match the query to be returned. Raising the threshold improves precision (fewer, more relevant matches) at the cost of recall; lowering it does the opposite. In this task you build a small Node.js + TypeScript CLI that demonstrates this trade-off end-to-end against the real Alchemyst AI service. ## Requirements - Project path: `/home/user/threshold-task`. Each document also gets a unique `file_name` suffixed with `-${run-id}`: - `python-${run-id}.md` — content describing the Python programming language (strong match for the verifier's query). - `js-${run-id}.md` — content describing the JavaScript programming language (loose match for the verifier's query). - `cake-${run-id}.md` — content describing baking a chocolate cake (unrelated to the verifier's query). `seed.ts` MUST be idempotent: before adding, best-effort delete any pre-existing document with the same `file_name`. 2. `search.ts` — accepts CLI flags `--query <text>` and `--threshold <number>`, performs a context search restricted to the run's group, and prints each retrieved chunk's `file_name` metadata to stdout on its own line. If a chunk has no `file_name` in its metadata, print its content instead. - Read `ZEALT_RUN_ID` from the environment in both scripts. - Read `ALCHEMYST_AI_API_KEY` from the environment. Do NOT mock the SDK and do NOT hardcode credentials. ## Implementation Hints - Storage metadata uses `group_name` (snake_case) in metadata while TypeScript search uses `groupName` (camelCase) in the `metadata` filter. See https://getalchemystai.com/docs/getting-started/quickstart#advanced-organize-with-metadata. - Use `client.v1.context.add({ documents: [...], context_type: 'resource', source: 'docs', scope: 'internal' })` to ingest. Each document should include `metadata: { file_name: '<name>-${run-id}.md', group_name: ['threshold-${run-id}'] }`. - Use `client.v1.context.search({ query, similarity_threshold: Number(threshold), scope: 'internal', metadata: { groupName: ['threshold-${run-id}'] } })`.

# Basic RAG Flow with Alchemyst AI (TypeScript SDK) ## Background Alchemyst AI is a Context Engine that provides AI agents with persistent memory and document-grounded retrieval. The TypeScript SDK (`@alchemystai/sdk`) exposes `v1.context.add` for ingesting documents and `v1.context.search` for retrieving relevant chunks by semantic similarity. Your job is to build a small Node.js TypeScript CLI that performs a minimal end-to-end RAG flow: ingest a refund-policy markdown document into the user's Alchemyst context store, then search it for a user question and print the retrieved chunks to stdout. ## Requirements * Project must be a Node.js TypeScript project located at `/home/user/myproject`. * Depend on `@alchemystai/sdk` and use the real Alchemyst API (no mocking). Authenticate using the `ALCHEMYST_AI_API_KEY` environment variable. * On startup, the CLI must add a refund-policy markdown document to the Alchemyst context store via `client.v1.context.add({...})`. The document content must clearly state that the company offers a `30-day` money-back refund policy. * The CLI must then search the context store via `client.v1.context.search({...})` using the question passed on the command line, and print the retrieved chunks to stdout. * The CLI must accept the user question as a `--question "<question>"` argument. * The CLI must be rerunnable: avoid 409 Conflict errors on repeated runs by making the document's `file_name` metadata unique per run. ## Implementation Hints * Read `run-id` from the `ZEALT_RUN_ID` environment variable and incorporate it into the document's `file_name` metadata (for example, something like `refunds-${run-id}.md`) so that re-runs in the same Alchemyst tenant do not collide. * Use the TypeScript SDK quirk: when calling `v1.context.add`, the metadata field is `group_name` (snake\_case), but when filtering in `v1.context.search`, the field is `groupName` (camelCase). You can keep this task simple by not filtering by group at all in search. * Suitable parameters for the simple case: `context_type: 'resource'`, `source: 'documentation'`, `scope: 'internal'`, and `similarity_threshold: 0.7`. * Use Node.js v24 (already installed in the environment) and TypeScript. You may compile with `tsc` and run with `node dist/main.js`, or run directly via `npm start`. Either approach is acceptable as long as the command shape below works. * Print the retrieved chunks in a clearly identifiable way (for example, print each `context.content` on its own line) so that downstream tooling can grep for keywords like `30-day` in stdout. * Reference: Alchemyst TypeScript SDK guide at https://getalchemystai.com/docs/tutorials/typescript-agent.md and the Contextual AI Quickstart at https://getalchemystai.com/docs/getting-started/quickstart. ## Acceptance Criteria * Project path: /home/user/myproject * Command: `npm start -- --question "<question>"` (run from `/home/user/myproject`). * Input argument format: `--question "<question text>"`. * The command must ingest the refund-policy document via `client.v1.context.add` on every invocation, using a `file_name` in metadata that is suffixed with the value of `ZEALT_RUN_ID` (e.g., `refunds-${ZEALT_RUN_ID}.md`). * The command must call `client.v1.context.search` with `scope: 'internal'` and a `similarity_threshold` no greater than `0.7`. * The command must print the retrieved chunk contents to stdout such that, when given a refund-related question, stdout contains the substring `30-day`. * The command must exit with status code 0 on success.
